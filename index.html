配置与获取

推荐配置 (Windows 玩家)

  • 操作系统：Windows 10 / Windows 11 (64位)
  • 内存分配：推荐分配 6GB 及以上
  • 运行环境：Java 17 (建议使用 Microsoft 或 Temurin 构建)
  • 游戏版本：Minecraft 1.20.1 (Forge 47.4.23)
点击查看详细系统兼容性要求 (Java 17 官方认证)
平台/环境 最低要求说明
Windows 官方最低 Windows 10 / Server 2016 x64 (不支持 32 位 Windows)
macOS 官方最低 macOS 10.15 Catalina（Intel）；Apple Silicon 需 macOS 11+
Oracle JDK RHEL / Oracle Linux 7.6+；Ubuntu 20.04 LTS；SLES 15 SP1+
OpenJDK RHEL / CentOS 7 系列 (Temurin/Corretto/Zulu 通常要求 glibc ≥ 2.17)
其他平台 Solaris 11.4；AIX 7.2 TL5+

*注：若在 Linux 服务器部署（如 CentOS 6 等老系统），请确保系统的 glibc 版本不低于 2.17，否则无法运行 Java 17。
